Privacy Policy

Last updated: 2026-11-02

youtube-manager is a personal tool used only by its owner to manage the owner's own YouTube channel. This policy explains how the app accesses, uses, stores and shares Google user data.

Data accessed

With the owner's consent (Google OAuth), the app accesses the owner's own YouTube account through the YouTube Data API and the YouTube Analytics API, using these scopes:

  • youtube and youtube.upload – to upload videos and edit titles, descriptions and tags of the owner's videos;
  • yt-analytics.readonly – to read the owner's channel statistics (views, watch time, subscribers).

How data is used

The data is used only to perform the actions above for the owner's own channel. It is not used for advertising, and it is not used to build user profiles.

Storage

The OAuth refresh token is stored only as an encrypted secret in the owner's private GitHub repository settings. Channel statistics are saved as plain files in the same private repository. No other copy is kept, and no third-party servers are used.

Sharing

Google user data is not sold, transferred or shared with anyone.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.

개인정보처리방침

youtube-manager는 소유자 본인이 자신의 유튜브 채널을 관리하기 위해서만 사용하는 개인용 도구입니다.

  • 접근하는 정보: 소유자 본인의 유튜브 채널 정보(영상 업로드·수정, 조회수·시청시간·구독자 통계). 소유자가 Google 로그인에서 동의한 범위에 한합니다.
  • 이용 목적: 본인 채널의 업로드, 제목·설명·태그 수정, 통계 확인. 광고나 프로필 생성에는 사용하지 않습니다.
  • 보관: 인증 토큰은 소유자의 비공개 GitHub 저장소의 암호화된 Secrets에만 저장되고, 통계 파일은 같은 비공개 저장소에만 저장됩니다.
  • 제3자 제공: 어떤 정보도 판매·이전·공유하지 않습니다.
  • 접근 해제: myaccount.google.com/permissions에서 언제든 해제할 수 있습니다.
