youtube-manager

A personal tool for managing my own YouTube channel / 내 유튜브 채널 관리용 개인 도구

What it does

youtube-manager is a private automation tool used by a single owner to manage the owner's own YouTube channel. Using the YouTube Data API and the YouTube Analytics API, with the owner's explicit consent, it can:

  • upload videos to the owner's channel,
  • update titles, descriptions and tags of the owner's videos,
  • read the owner's channel statistics (views, watch time, subscribers) to track progress.

It is not offered to the public and is not used by anyone other than its owner.
